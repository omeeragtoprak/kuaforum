# Pazara Çıkış (GTM) Stratejisi

> 9-15 ay sonunda **production-grade MVP** + soft-launch + ulusal yayılma. Marketplace cold-start riskine karşı **supply önden + pilot şehir disiplini**.

---

## 1. Faz Yapısı

```
Phase 0    →   Phase 1    →   Phase 2     →   Soft-launch    →   Açık launch    →   Ölçek
(Foundation)  (Backbone)    (Marketplace)    (1 pilot şehir)    (3 büyükşehir)    (Ulusal)
  Ay 1         Ay 2-3        Ay 4-7            Ay 9-11             Ay 12-15        Ay 16+
```

---

## 2. Pre-launch — Phase 0 Sonu (Customer Discovery Sprint)

**Süre:** 2 hafta.
**Hedef:** Hipotezlerin doğrulanması + pilot şehir kararı.
**Detay:** [`docs/13-project-management/05-customer-discovery-plan.md`](../13-project-management/05-customer-discovery-plan.md).

**Çıktı:**
- Hipotez başına onay/red durumu.
- Pilot şehir önerisi.
- Persona doğrulama.
- 30+ kuaför ön niyet beyanı.

---

## 3. Phase 1+2 — Pre-launch Marketing (Background Build)

Kod yazımı paralelinde:
- **Bekleme listesi sayfası** (`kuaforum.com`) — Phase 1 başında. E-posta toplama, "ilk açılan kuaför hediye yorumu" gibi.
- **Sosyal medya** Instagram + TikTok (kuaför + saç içeriği) — Phase 2'den itibaren haftalık post (founder).
- **PR temas:** Pilot şehirde yerel medya, podcast (Phase 2 sonu).
- **İçerik marketing:** "Kuaför randevu rehberi", "Saç bakım ipuçları" SEO blog (admin paneline yan içerik bölümü).

---

## 4. Soft-Launch — 1 Pilot Şehir (Ay 9-11)

### Pilot şehir seçim kriterleri
- Şehir nüfusu **500K - 2M** (terlemeden likidite + yeterli pazar).
- Founder'a coğrafi ulaşım kolay.
- Booksy/Fresha aktif değil.
- Üniversite şehri olması bonus (genç müşteri tarafı kolay).

**Adaylar (Phase 1 sonu kararı):** Bursa · Eskişehir · Konya · Antalya · Adana.

### Önceden niyet (pre-commitment)
- 30+ kuaför Phase 1 sonu kişisel görüşme + niyet imzası.
- Onboarding sırası: önce 5-10 "anchor" kuaför (yerel etkili), sonra geri kalan.

### Müşteri kazanım
- **Davetiye-only ilk 1 ay** (FOMO + kalite kontrol).
- **Açık kayıt 2. aydan itibaren** + her ilk randevuda %20 indirim (platform sübvanse).
- **Influencer:** 2-3 yerel saç & güzellik içerik üreticisi, hediye randevu.
- **Sokak marketing:** Pilot şehirde kuaförlerin önünde sticker / poster.

### Metrik hedefleri (3 ay)
| Metrik | Hedef |
|---|---|
| Aktif kuaför | 30 → 80 |
| Aylık aktif müşteri | 0 → 5.000 |
| Aylık tamamlanan randevu | 0 → 4.000 |
| GMV | 0 → 1.5M TL/ay |
| NPS (her iki taraf) | > 35 |
| Tamamlanma oranı | > %85 |
| No-show | < %10 |
| Kuaför retention (ay 3) | > %80 |
| Müşteri retention (ay 3) | > %25 |

### Soft-launch G3 Gate
Eğer 3 ay sonunda hedeflerin %80'i tutturulmazsa: **iyileştirme dönemi** (ek 6-8 hafta) + tekrar değerlendirme.

---

## 5. Açık Launch — 3 Büyükşehir (Ay 12-15)

### Şehir seçimi
- **İstanbul** (Anadolu yakası önce — Kadıköy + Ataşehir + Üsküdar).
- **Ankara** (Çankaya + Yenimahalle).
- **İzmir** (Bornova + Konak + Karşıyaka).

### Marketing
- **Paid kanallar:** Google Ads + Instagram + TikTok ads. **Bütçe:** ₺25-50K/ay başlangıç.
- **PR:** Saç & güzellik blog/podcast/influencer takım dosyası.
- **Referral programı:** Müşteri-müşteri (50 TL kredi her iki taraf).
- **Kuaför referans:** Kuaför-kuaför (1 ay komisyon indirimi).

### Operasyon
- **Customer support:** Crisp.chat veya Intercom + 1-2 part-time destek.
- **Müşteri başına edinim maliyeti (CAC):** Hedef < 80 TL.
- **Lifetime value (LTV):** Hedef > 600 TL (yıl 1).
- **LTV / CAC oranı:** > 7.5x sürdürülebilir.

### 12 ay sonu metrikler
| Metrik | Hedef |
|---|---|
| Aktif kuaför | 300+ |
| Aylık aktif müşteri | 30.000+ |
| Aylık tamamlanan randevu | 25.000+ |
| GMV | 8M+ TL/ay |
| NPS | > 40 |
| Tamamlanma oranı | > %85 |

---

## 6. Ölçek (Ay 16+)

- Yeni şehirler ekleme — kuaför ön niyet + müşteri talep yoğunluğuna göre.
- Booksy TR girişi takibi → **defansif** strateji (compliance moat + müşteri sadakat + B2B SaaS modülü).
- A/B testler (komisyon tier'ları, premium abonelik).
- B2B SaaS modülü pazara çıkar (V2).
- Yatırım turu (gerekirse) — Series A.

---

## 7. Risk & Karşı Önlem

| Risk | Önlem |
|---|---|
| **Cold-start (R2)** | Pilot şehir + 30 kuaför ön niyet + concierge MVP. |
| **Booksy giriş (R1)** | Hız + KVKK/e-Arşiv compliance moat + lokal kuaför ilişkileri. |
| **Marketing bütçe yetersiz** | Organik (içerik + influencer barter) + cold-launch davetiye-only. |
| **Düşük tamamlanma oranı** | Kademeli iade + push hatırlatma + kuaför "boşum" alarmı. |
| **Düşük kuaför retention** | T+1 ödeme + e-Arşiv otomasyonu + müşteri akışı kanıtla. |

---

## 8. Geri Çekilme Planı (Worst Case)

Eğer 6 ay sonunda metrikler %50 altında:
1. **Pivot karar gate.** RFC ile pivot opsiyonları.
2. Olası pivot: **B2B SaaS** (yerli pazarın gerçek talebi). Pazaryeri tarafı V2'a kaymış.
3. Veya: **Hyperlocal** — sadece 1 şehir + sadık küçük topluluk.
4. Veya: **Ölçek dışı kapatma** — kayıp kabul + dersi öğren.

Founder + Claude bu kararı **dürüstçe** ve **erken** alır. Sunk cost'a yenilmez.
